Crie um protótipo UI/UX de alta fidelidade para uma plataforma chamada **BIOSYN**, uma plataforma de inteligência e análise em saúde pública movida por IA, focada em transformar dados complexos de saúde em insights acionáveis para gestores, analistas e tomadores de decisão governamentais.

O protótipo deve transmitir a sensação de uma fusão entre:

* Palantir Gotham
* Microsoft Fabric
* Oracle Analytics Cloud
* Dashboards modernos de health-tech SaaS
* Sistemas de monitoramento emergencial (Defesa Civil / centros de crise)

A linguagem visual deve comunicar:

* confiança
* inteligência
* análise preditiva
* governança em saúde pública
* controle operacional
* tecnologia de saúde futurista
